# MelosViz — Music Video Production Guide

Goal: ship a **digitally created, multi-scene, 3-5 minute music video**
that holds up on a festival/club screen _and_ on YouTube. Beat-synced,
visually varied, and telling a story no matter how abstract.

This guide walks you from "I have a WAV file" to "I have a master MP4 +
festival ProRes + audio stems" using the MelosViz studio pipeline.

---

## 0. Tools you need

| Tool                                 | Why                                                        | Where                                                                             |
| ------------------------------------ | ---------------------------------------------------------- | --------------------------------------------------------------------------------- |
| **ComfyUI**                          | Primary generative renderer (images + video). Local, free. | `https://github.com/comfyanonymous/ComfyUI` — `python main.py`                    |
| **Cinema 4D** _(optional)_           | High-end 3D scenes                                         | `https://www.maxon.net/cinema-4d/` — install + put `Commandline.exe` on `$PATH`   |
| **Unreal Engine 5** _(optional)_     | Real-time cinematic / Nanite / Lumen / MetaHuman           | `https://www.unrealengine.com/` — build a project with Movie Render Queue enabled |
| **DaVinci Resolve** _(optional)_     | Final color + audio mix + master encode                    | `https://www.blackmagicdesign.com/products/davinciresolve` — Resolve 18+          |
| **After Effects** _(optional)_       | Per-scene motion graphics, beat-synced MOGRTs              | Adobe Creative Cloud                                                              |
| **Adobe Media Encoder** _(optional)_ | Concat per-scene clips into master timeline                | Adobe Creative Cloud                                                              |
| **ffmpeg**                           | Universal fallback for assemble / master / ship            | `brew install ffmpeg`                                                             |

Any missing tool degrades gracefully — MelosViz emits a structured
job-spec JSON instead of crashing (see `SPEC.md §11.4`).

## 1. The pipeline in one picture

```
WAV file
   │
   ▼
viz analyze        →  RenderSpec v2 (BPM, beats, segments, palette hints)
   │
   ▼
viz storyboard     →  ShotList JSON (5-8 scenes, each with prompt, camera, palette, motion)
   │
   ▼
viz generate       →  Per-scene clips via ComfyUI / C4D / Unreal / AE
   │
   ▼
viz assemble       →  rough.mp4 (concat per-scene clips via AME or ffmpeg)
   │
   ▼
viz master         →  festival ProRes / club 1080p H.264 / YouTube 1080p H.264
   │
   ▼
viz ship           →  final.zip (MP4 + ProRes + audio stems + SRT captions)
```

---

## 2. Step 1 — Analyze

```bash
viz analyze track.wav --out spec.json
```

Output: `RenderSpec v2` JSON. Includes `metadata` (duration, fps, bpm),
`palette` (auto-derived from the audio's spectral centroid trajectory),
`scene_segments` (intro / verse / chorus / bridge / outro), and
`timeline_events` (beats, downbeats, onsets).

---

## 3. Step 2 — Storyboard

```bash
viz storyboard track.wav \
  --concept "abstract underwater city, bioluminescent, slow motion, 35mm film" \
  --bpm 124 \
  --palette "#0d0d10 #ff2bd6 #22d3ee" \
  --out storyboard.json
```

You can also pin a **continuity reference image** (v2, WBS-2) so the
same face / style carries into every scene via ComfyUI IP-Adapter / Wan
/ ControlNet. The path is validated for existence; missing files are
dropped with a warning rather than aborting the render.

```bash
viz storyboard track.wav \
  --concept "neon-noir dancer in a rainy city, 35mm" \
  --reference-image ./refs/protagonist.png \
  --out storyboard.json
```

The `--reference-image` flag is also exposed on `viz generate` and
`viz direct` so an art-director can pin / re-pin the reference at any
stage without re-running `viz storyboard`.

Output: a shot list with **5-8 scenes**, each carrying:

- `prompt` — descriptive text for ComfyUI / C4D / UE / AE
- `camera` — `dolly_in`, `orbit`, `static`, `pullback`, etc.
- `palette_hint` — `neon`, `warm`, `cool`, `monochrome`
- `motion` — `slow`, `medium`, `fast` (mapped to `comfyui_video` if
  motion > medium)
- `beats` — list of beat indices within the scene for tight sync
- `duration_s` — scene length derived from segment start/end
- `seed` — deterministic seed for reproducible renders
- `continuity.reference_image` — path to the IP-Adapter / style
  reference image (v2, WBS-2). Inherited from the storyboard-level
  `--reference-image` flag when supplied; `None` when omitted.

### Director LLM (optional)

If you set `MELOSVIZ_DIRECTOR_LLM`, `MELOSVIZ_DIRECTOR_API_KEY`, and
`MELOSVIZ_DIRECTOR_MODEL`, the storyboard will be generated by an LLM
that ingests the MIR analysis. Otherwise, a deterministic template
fallback produces solid storyboards using the palette / BPM / segment
labels.

---

## 4. Step 3 — Generate (per-scene renders)

```bash
viz generate track.wav \
  --storyboard storyboard.json \
  --out ./out
```

This runs every scene through the correct adapter:

- `comfyui_image` scenes → `ComfyUIAdapter` (SDXL or Flux) → `*.png`
- `comfyui_video` scenes → `ComfyUIAdapter` (Wan 2.1) → `*.mp4`
- `c4d_3d` scenes → `C4DAdapter` (Cinema 4D headless) → `*.exr` sequence
- `unreal_cinematic` scenes → `UEAdapter` (UE5 Movie Render Queue) → `*.png` sequence
- `motion_graphics_beat_sync` scenes → `AEAdapter` (nexrender / aerender) → `*.mov`

If a backend tool is missing, the adapter emits a `<scene>_plan.json`
you can drive manually:

```
out/
├── job_spec.json          # what the orchestrator did
├── scene_000/
│   ├── workflow.json      # ComfyUI prompt graph (open in ComfyUI GUI)
│   └── render_manifest.json
├── scene_001/
│   ├── c4d_render_plan.json
│   └── ...
└── ...
```

### ComfyUI offline mode (CI / laptop without GPU)

```bash
MELOSVIZ_COMFYUI_OFFLINE=1 viz generate track.wav \
  --storyboard storyboard.json \
  --out ./out
```

Every scene gets a per-scene `workflow.json` — open them in the ComfyUI
GUI, hit "Queue Prompt", and the renders start. Workflow JSON = fully
reproducible.

### Native-audio video workflows (Wan 2.1 S2V + Seedance A2V) — WBS-107..109

Two audio-conditioned diffusion workflows ship out of the box for music
videos where the audio track should drive motion (rather than the usual
"image → optional ambient audio" pipeline):

| Scene archetype               | Workflow template    | Adapter scene type             |
| ----------------------------- | -------------------- | ------------------------------ |
| `drop`                        | `wan_s2v_audio.json` | `comfyui_audio_video_wan`      |
| `chorus` (+ character anchor) | `seedance_a2v.json`  | `comfyui_audio_video_seedance` |
| `chorus` (no character)       | `wan_s2v_audio.json` | `comfyui_audio_video_wan`      |

The Director routes automatically (see `melosviz/llm/director.py`
`_ARCHETYPE_DEFAULTS`). To force audio-conditioned video on every
chorus / drop scene even without a pinned character, pass the CLI flag:

```bash
viz storyboard track.wav --concept "neon festival" \
    --audio-conditioned-video --out ./plan
```

The orchestrator stamps `audio_path`, `motion_strength`, and
`audio_influence` onto every audio-conditioned scene before dispatch
(see `Orchestrator.run` → `_audio_scene_types` block), so the workflow
templates only need `{audio_path}` placeholders.

---

## 5. Step 4 — Assemble (concat per-scene clips)

```bash
viz assemble ./out --out ./rough.mp4
```

Runs `ame` if installed (Adobe Media Encoder batch mode), otherwise
falls back to ffmpeg's `concat` demuxer. The rough cut is your
**unedited master** — every scene joined end-to-end with a 2-frame
crossfade.

---

## 6. Step 5 — Master (color + audio mix + deliverables)

```bash
viz master ./rough.mp4 --out ./master
```

Outputs three deliverables in `./master/`:

- `festival_master.mov` — ProRes 422 HQ, 1920×1080, 24fps, 48 kHz audio
  (for projection at clubs/festivals)
- `club_1080p.mp4` — H.264 high profile, 1920×1080, 24fps, AAC 320 kbps
  (for club screens with limited bandwidth)
- `youtube_1080p.mp4` — H.264 high profile, 1920×1080, 24fps, AAC 256 kbps,
  faststart (for direct YouTube upload)

If DaVinci Resolve isn't installed, falls back to ffmpeg + a baked
color LUT (you can replace the LUT with your own .cube file via
`MELOSVIZ_COLOR_LUT`).

---

## 7. Step 6 — Ship (package + captions + stems)

```bash
viz ship ./master --out ./final.zip
```

Produces `./final.zip` containing:

- `festival_master.mov`
- `club_1080p.mp4`
- `youtube_1080p.mp4`
- `audio_stems/` — `drums.wav`, `bass.wav`, `vocals.wav`, `other.wav`
  (when Demucs separation ran during analyze)
- `captions.srt` — auto-generated from lyrics if you pass
  `--lyrics lyrics.txt` to `viz analyze`, otherwise beat-marker captions
- `storyboard.json` — the source of truth for what was rendered
- `manifest.json` — full provenance (seeds, prompts, models, durations)

---

## 8. End-to-end one-liner

```bash
viz analyze track.wav \
  --lyrics lyrics.txt \
  --out spec.json \
&& viz storyboard track.wav \
     --concept "abstract underwater city, bioluminescent, 35mm" \
     --bpm 124 \
     --palette "#0d0d10 #ff2bd6 #22d3ee" \
     --out storyboard.json \
&& viz generate track.wav \
     --storyboard storyboard.json \
     --out ./out \
&& viz assemble ./out --out ./rough.mp4 \
&& viz master ./rough.mp4 --out ./master \
&& viz ship ./master --out ./final.zip
```

Run that, grab `final.zip`, upload `youtube_1080p.mp4` to YouTube,
hand `festival_master.mov` to the VJ for the club show.

## 9. Troubleshooting

| Symptom                                          | Cause                             | Fix                                                                                                            |
| ------------------------------------------------ | --------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| `ComfyUI not reachable at http://127.0.0.1:8188` | ComfyUI isn't running             | `cd ComfyUI && python main.py` then re-run `viz generate`                                                      |
| `c4d: Cinema 4D binary not found`                | C4D not on `$PATH`                | Install C4D or set `MELOSVIZ_C4D_BIN=/Applications/MAXON Cinema 4D/Commandline.app/Contents/MacOS/Commandline` |
| `unreal_cinematic: UnrealEditor-Cmd not found`   | UE5 not on `$PATH`                | Set `MELOSVIZ_UE_BIN=/Users/you/UnrealEngine/Engine/Binaries/Mac/UnrealEditor-Cmd`                             |
| Output looks boring / repetitive                 | Template fallback is too rigid    | Set `MELOSVIZ_DIRECTOR_LLM` + `MELOSVIZ_DIRECTOR_API_KEY` to use the LLM director                              |
| Render flashes too much (epilepsy concern)       | Palette is too saturated          | Lower `--cfg` in the ComfyUI workflow, or pick a `cool`/`monochrome` palette hint                              |
| Final video is desynced                          | Audio analysis used a wrong tempo | Pass `--bpm 124` explicitly to `viz storyboard`                                                                |

## 10. Where the real work happens

The hard part isn't the pipeline — it's the **art direction**. Here's
what makes a 3-5 minute music video _feel_ like a story instead of a
loop:

1. **Pick a concept** that matches the song's mood. A ballad wants slow
   motion + monochrome; a banger wants fast cuts + neon. The director
   agent picks the right scene types per segment, but it can't pick the
   _concept_ for you.

2. **Vary the scenes.** No two adjacent scenes should use the same
   camera move. The director agent enforces this. If you see two
   `orbit` scenes next to each other in `storyboard.json`, edit it.

3. **Sync the cuts to the beats.** The default scene boundaries are
   structural (intro/verse/chorus) — but the _cuts_ inside a scene
   should land on downbeats. Pass `--bpm` so the director can align
   them.

4. **Don't over-direct.** Three scenes with the same prompt but
   different seeds, played back-to-back, is more interesting than three
   scenes with three wildly different prompts.

5. **Bake the color, then push it.** Run `viz master` once with the
   default LUT, watch the rough cut, then override `MELOSVIZ_COLOR_LUT`
   with a `.cube` file tuned to your palette.
