# MelosViz internationalization

Minimal catalog-based i18n for the web surface (no heavy framework).

| Locale | File | Status |
|--------|------|--------|
| `en` | `web/src/i18n/locales/en.json` | default |
| `es` | `web/src/i18n/locales/es.json` | partial UI strings |

```ts
import { t, setLocale } from "./i18n";
setLocale("es");
t("action.analyze"); // → "Analizar"
```

Override at build/runtime with `MELOSVIZ_LOCALE=es`. Desktop shell remains
English-first; bridge/CLI messages stay English (operator surface).

Adding a locale: copy `en.json`, translate values, register in `index.ts`.
