# MelosViz internationalization

Minimal catalog-based i18n (no heavy framework). **Status (WBS-P3.5):** en/es catalogs
cover CLI argparse help + runtime errors, desktop shell chrome (sidebar, pipeline,
progress, empty state, tabs), web splash/loading/playlist/empty/error strings,
web keyboard-help / preset-editor chrome (shortcuts dialog, editor labels,
built-in preset names), bridge-down analysis errors, first-visit onboarding
banner, analysis cancel affordance, playlist batch-progress strings, and
**studio polish keys added W-358–376** (playback transport, fullscreen toggle,
scene-jump panel chrome, keyboard section/label chips, preset quick-apply,
spec summary line, analysis progress live region). **Honest residual:** RenderSpec
`scene` names (demo placeholder + server keyframes) and the left-panel `h1` brand
spellings stay English-first; only panel chrome / aria / button labels are localized.

| Surface | Locales | Catalog | Wired today |
|---------|---------|---------|-------------|
| Web | `en` (default), `es` | `web/src/i18n/locales/*.json` | Splash, loading, actions, playlist, analysis/bridge errors, onboarding, keyboard help, preset editor + quick-apply, PlaybackTransport, fullscreen, scene-jump panel via `t()` / `tf()` |
| CLI | `en` (default), `es` | `backend/src/melosviz/i18n/locales/*.json` | argparse description, subcommand `help=`, arg `help=`, stderr errors |
| Desktop | `en` (default), `es` | `desktop/locales/*.json` | titlebar, tray, skip-link, status/progress/errors, `applyShellChrome()` labels |

```ts
// web
import { t, tf, setLocale } from "./i18n";
setLocale("es");
t("action.analyze"); // → "Analizar"
tf("error.analysis_server", { status: 500, statusText: "Error" });
```

```python
# CLI
from melosviz.i18n import t
t("cli.analyze.help")
t("cli.error.file_not_found", cmd="analyze", path="/x.wav")
```

Override at build/runtime with `MELOSVIZ_LOCALE=es` (web, CLI, desktop).
CLI also honors the env var when printing `--help`.

## Key parity

`en.json` and `es.json` must expose the same keys per surface. CI tests:
`backend/tests/test_i18n.py`, `web/src/test/i18n.test.ts`.

Adding a locale: copy the `en.json` for that surface, translate values, register
in the surface's `index` / `__init__` loader.
